# Shivam Kumar Gupta Portfolio

GitHub Pages portfolio for Shivam Kumar Gupta.

## Local Preview

Open `index.html` directly in a browser, or run a small static server from this folder:

```bash
python3 -m http.server 8000
```

## GitHub Pages

The deploy workflow uses GitHub Actions. For the first deploy, either enable Pages in the repository settings and set the source to GitHub Actions, or add a repository secret named `PAGES_TOKEN` with repo/admin Pages access so the workflow can enable Pages automatically.
